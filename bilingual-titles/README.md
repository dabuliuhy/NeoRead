# 双行标题 · Bilingual Titles 1.0.0

在 Zotero 文献列表中，将原文标题与已有中文译文合并为上下两行，便于快速浏览。

## 主要功能

- **双行标题**：上方显示原题，下方显示译文；没有译文时仅显示原题，长标题可悬停查看。
- **列布局优化**：可隐藏单独的译文列，设置其他列居中、长内容最多两行换行及紧凑行距。
- **保留原有数据**：不修改文献标题、元数据或引用导出；停用后恢复原生显示。

插件只显示已有译文，不生成翻译。它读取文献「其他 / Extra」中的 `titleTranslation: 中文标题`，也识别 `Title Translation`、`translatedTitle`、`标题翻译` 等字段。无需 API Key，不发送网络请求，可独立使用。

## 安装与使用

适用环境：Windows / Zotero 10.0.8；安装包限定 Zotero 10.0.x。

1. 在 Zotero 中打开「工具 → 插件 → 齿轮 → 从文件安装插件」，选择本目录的 `bilingual-titles-1.0.0.xpi`。
2. 安装后自动生效，在「工具 → 双行标题」中调整显示选项。

双行显示会增加行高；可通过紧凑行距提高每屏显示数量。当前使用 XPI 手动更新。

如需重新打包，在本目录使用 Node.js 20 或更高版本运行 `node scripts/build.cjs`，无需安装 npm 依赖。安装和使用 XPI 不需要 Node.js。
