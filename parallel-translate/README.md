# 双语研读 · Parallel Translate 1.0.0

在 Zotero 中翻译和阅读 PDF 文献。正式版以原 1.2.8 最新代码为基础，版本号统一为 1.0.0。

## 主要功能

- **双语阅读**：在阅读标签页切换原文、译文和逐段上下对照，支持目录、图表导航和原文定位。
- **全文与批量翻译**：支持任务队列、暂停与继续、译文缓存、局部重译，以及完成后自动添加文献标签。
- **公式与图表**：支持公式排版、图表弹窗、PDF 原图展示及侧向表格自动转正；可选 AI 公式和整体排版。
- **注释与校订**：在原文上创建 Zotero 注释，校订英文内容，并调整字体、字号、行距和阅读主题。
- **模型配置**：支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 及相应兼容接口，可设置模型、推理强度和翻译要求。

## 安装与使用

适用环境：Windows / Zotero 10.0.8；安装包限定 Zotero 10.0.x。

1. 在 Zotero 中打开「工具 → 插件 → 齿轮 → 从文件安装插件」，选择本目录的 `parallel-translate-1.0.0.xpi`。
2. 重新打开 PDF，点击阅读工具栏的双页图标，在设置中填写接口地址、API Key 并选择模型。
3. 保存设置后开始翻译；也可在文献列表中选中文献，通过右键菜单「『译』双语阅读」加入任务。

从开发版 1.2.8 切换时请手动安装此 XPI。插件 ID 保持不变，沿用已有设置与译文缓存；当前不提供自动更新服务。

翻译会向所配置的模型服务发送待处理内容，并可能产生 API 费用。译文缓存保存在 Zotero 数据目录的 `parallel-translate` 文件夹；不改写原 PDF，不生成翻译版 PDF。复杂公式、扫描件和特殊版面仍需人工核对。

## 文件与构建

- `addon/`：最新运行脚本、样式、图标及依赖资源。
- `scripts/build.cjs`：独立打包脚本。
- `parallel-translate-1.0.0.xpi`：可直接安装的插件；同名 `.sha256` 文件用于完整性校验。
- `LICENSE`：MIT 许可证；第三方资源附各自的许可证。

如需重新打包，在本目录使用 Node.js 20 或更高版本运行 `node scripts/build.cjs`，无需安装 npm 依赖。安装和使用 XPI 不需要 Node.js。
